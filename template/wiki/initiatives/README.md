# initiatives/

Ongoing goals and programs without a fixed end: "build the team's on-call maturity," "grow a professional network in X," "keep the reading habit." Recurring prompts the principal asks for usually hang off an initiative page (see `CLAUDE.md`, "Recipe: recurring proactive prompts").

**Frontmatter**

```yaml
---
type: initiative
tags: []
created: YYYY-MM-DD
updated: YYYY-MM-DD
status: <active|paused|parked|retired>
phase: <idea|exploring|running|maintaining>
priority: <1-N>
---
```

**Suggested sections:** why it matters, what good looks like, current cadence, related projects, history of decisions.
