# Wiki Index

The content catalog for {{PRINCIPAL_NAME}}'s world and the navigation root for every query. Bootstrap read #6.

**Who writes here:** only the Librarian (`subagents/librarian/`). Everyone else, {{AGENT_SHORT}} included, proposes changes through `subagents/librarian/submissions/`. **Who reads here:** every agent.

**How to use this page:** find candidate pages by folder, read their summaries here, then drill in. A good row tells a reader what the page holds and what it is load-bearing for, including any caveat a reader must know before citing it. If a row is thin, that is a Librarian lint finding.

## Folder map (profile: `{{PROFILE}}`)

| Folder | What goes there | Typical `type` |
|--------|-----------------|----------------|
| [`people/`](people/) | The principal (`principal.md`) and individuals who matter outside a work relationship | `person` |
| [`stakeholders/`](stakeholders/README.md) | People the principal works with or for: manager, reports, peers, customer contacts, external partners | `stakeholder` |
| [`organizations/`](organizations/README.md) | Employer, teams, customers, vendors, partners | `organization` |
| [`projects/`](projects/README.md) | Bounded efforts with a deliverable and an end date | `project` |
| [`initiatives/`](initiatives/README.md) | Ongoing goals and programs without a fixed end | `initiative` |
| [`concepts/`](concepts/README.md) | The principal's frameworks, theses, playbooks, methodologies, recurring patterns | `concept` |
| [`writings/`](writings/README.md) | Pieces the principal has published, one page each | `writing` |
| [`archive/`](archive/README.md) | Wound-down or superseded material kept for history | `archive` |

**Why this shape.** A work life is mostly people, organizations and bounded deliverables, so those get first-class folders. `projects/` vs `initiatives/` is the "does it end?" test: a migration ends, "grow the team's on-call maturity" does not. For a `personal` profile you may rename `organizations/` to `businesses/` and `stakeholders/` to `clients/`; keep the frontmatter `type` values in sync and update this table.

Module-owned folders (for example `health/`, `finance/`, `topics/`) are added by the Librarian when a module that needs them is installed. Each gets a row in the folder map and its own section below.
