# archive/

Wound-down or superseded material kept for history: finished projects that no longer inform current work, former organizations, retired playbooks, old content worth mining later.

**Rule:** nothing in the wiki is deleted. Pages evicted from active folders move here with `type: archive` (or keep their type and set `status` to a terminal value) and a one-line note at the top saying when and why they moved.

Written only by the Librarian.
