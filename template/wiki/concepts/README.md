# concepts/

The principal's frameworks, theses, playbooks, methodologies and recurring patterns. A concept page records how the principal thinks, so agents can apply it without asking again.

**Frontmatter**

```yaml
---
type: concept
tags: []
created: YYYY-MM-DD
updated: YYYY-MM-DD
category: <thesis|framework|pattern|methodology|strategy|playbook|tool>
---
```

Concept pages are timeless and do not carry `status`.

**Defined processes.** If the principal defines a process with exact commands or steps, put it here verbatim and link it from `USER.md` "Defined processes." Agents use it verbatim.

**External corpora** (someone else's atomic principles the principal wants applied) live in a subfolder with an `index.md` of `type: index` that carries the corpus's controlled vocabularies in its frontmatter. Ingestion is verbatim only.
