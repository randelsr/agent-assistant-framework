# plans/

One file per week: `YYYY-MM-DD-week.md`, dated by that week's Monday.

Sections:
- `Status:` kickoff-sent | proposed | approved | cooked
- `Menu` (table: Day · Meal · Main protein · Cuisine/style · Category)
- `Changes` (every request, in order, with who asked)
- `Recipes` (full text, or links to `../recipes/`)
- `Shopping list` (Produce · Meat & Fish · Dairy & Refrigerated · Dry Goods · Pantry Staples)
- `Audit` (`N ingredients across M recipes checked, 0 missing.`)
